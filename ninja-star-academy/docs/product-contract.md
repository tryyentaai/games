# Ninja Star Academy

Audience: a ninja-loving child around five using an iPhone with a parent.

Core loop: choose a short mission, practice one gesture, finish without a failure screen, celebrate, earn stars, and unlock a scarf or build the twelve-sticker album.

Missions: Sky Run (auto-run, jump/double jump, forgiving obstacle recovery, fifteen stars or forty active seconds); Star Throw (twelve wooden targets, tap to aim or assisted Throw button); Lantern Pop (twelve lanterns, swipe/tap or assisted Pop button). No lives, ads, purchases, chat, game accounts, or analytics.

Acceptance journeys: complete and replay a mission; finish all three and use the rewards/wardrobe/collection; pause/resume, change settings, reload and retain valid progress. Browser-local backups can preserve valuable progress. Offline shell/asset caching is scoped to this app and must preserve sibling games.

Delivery: buildless static PWA in the existing public games repository and GitHub Pages path. Do not alter sibling projects or repository visibility. Report browser-versus-physical-device limits. This release is a browser-verified beta; physical iPhone installation, actual offline launch, accessibility and on-device performance verification remain outstanding.
